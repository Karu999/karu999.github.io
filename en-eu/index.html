Windows · competitive

Settings for the match, then back.

KARU Tweaks is a Windows app. Game Mode applies the competitive set while a detected game is open and restores it when you press Stop. Fortnite and Valorant keep their own config files. BIOS rows that Windows cannot change stay as steps in the BIOS menu.

Download 0.1.45 See what it does
01

Game Mode

One apply for the open game. CPU, capture, and the timer change for that session. Stop puts the saved values back.

02

Each game

Fortnite writes its own graphics file, with view distance left at medium. Valorant gets fullscreen and VSync off. Vanguard stays on.

03

Premium

General Windows switches are free. The competitive pages are 45 EUR. Every paid switch has a restore.

Windows 10 and 11

The installer is KARU Tweaks 0.1.45. Run it on the PC you play on. The app reads the current settings before it changes them.
